This directory contains Flatpak packaging for Cloudy AF (arcticfox-config).

Upstream source: https://github.com/VernaUpon74/cloudy-af

This copy was added to the local flathub fork by automation on branch org.cloudy.af.

Notes:
- The manifest in flatpak/org.cloudy.af.yml expects the application source to be present
  as a directory relative to the manifest (it was authored to be used from the source repo).
- For Flathub app submissions we usually adapt the manifest to fetch sources from the
  upstream repository or provide a stable tarball. If you want, I can create a
  Flathub-style manifest that fetches the release tarball instead.
